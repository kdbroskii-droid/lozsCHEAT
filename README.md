# LOSZ

First-stage menu interface prototype for the LOSZ project.

## Preview

Open [menu-preview.html](./menu-preview.html) in a browser to view and interact with the menu.

## Included in v0.1

- Blue rounded top-left menu panel
- General, Visuals and Settings tab styling
- Toggle controls and adjustable sliders
- Keyboard navigation
- Basic gamepad navigation (D-pad / left stick and ✕)
- L1 + R1 visibility toggle where the browser exposes those gamepad buttons

## Scope

This is a standalone UI preview only. It is not a PS4 plugin and does not hook into Fortnite or modify gameplay. The menu controls currently demonstrate interface behaviour only.

## Controls

- Keyboard: Up / Down to select, Left / Right to adjust, Enter to toggle
- Gamepad: D-pad or left stick to navigate, ✕ to activate
- L1 + R1: show or hide the panel
